# Speech to Speech Translate

### Overview

Speech to Speech Translate is an advanced level project that combines multiple features into one single web application. It contains translate text, convert text into speech, sentiment analysis of message, and many more.

### Tech Stack

* Python
* Streamlit
* GoogleTranslator
* gTTS
* pydub
* speech_recognition
* transformers

### Environment (IDE)

1. VS Code
